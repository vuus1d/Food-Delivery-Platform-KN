Foodly is a front-end web application for comparing grocery prices across supermarkets in Astana.

The platform provides a single interface where users can explore supermarkets, compare product prices, and prepare a delivery order.

## Project Mission

The main goal of Foodly is to make everyday groceries more accessible and affordable for people in Astana.

Foodly helps users:

- Compare prices between different supermarkets.

- Find more affordable options for everyday products.

- Reduce the time spent checking prices across different stores.

- Make informed purchasing decisions.

- Simplify the grocery shopping process.

By bringing supermarket information and prices together in one place, Foodly aims to help users save both **money and time** while making essential products more accessible.

## Code Layout

The repository has the following structure:

    index.html : Main landing page.

    store.html : Supermarket directory.

    compare.html : Product price comparison.

    cart.html : Checkout page.

    css/

        style.css : Shared stylesheet.

    js/

        app.js : JavaScript functionality.

    README.md : Project documentation.
